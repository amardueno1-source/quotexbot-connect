quotexbot Chrome MV3 extension  v0.9.13
=======================================

Load unpacked (English)
-----------------------
1. Open chrome://extensions
2. Turn on Developer mode (top-right)
3. Click "Load unpacked"
4. Select the chrome folder (the folder that contains manifest.json)
5. Open your Quotex DEMO trade tab. The HUD pins bottom-left ON the chart.
6. Disable Tampermonkey quotexbot so two HUDs do not stack.

আনপ্যাক করে লোড (বাংলা)
-----------------------
1. chrome://extensions খুলুন
2. উপরে-ডানে Developer mode চালু করুন
3. "Load unpacked" চাপুন
4. chrome ফোল্ডার সিলেক্ট করুন (যেখানে manifest.json আছে)
5. Quotex DEMO ট্রেড ট্যাব খুলুন — HUD চার্টের নিচে-বামে দেখাবে
6. Tampermonkey-এ quotexbot বন্ধ করুন, দুইটা HUD যাতে না আসে

Then disable Tampermonkey quotexbot.

DEMO only. Visible DOM. No cookies / SSID / unofficial APIs.
Stay on the open chart. Auto clicks Up/Down on DEMO only.
