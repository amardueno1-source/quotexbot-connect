# quotexbot Connect (Tampermonkey)

Paper/DEMO helper for an already-open Quotex-style OTC tab.

- Stays on the trade page (HUD does not close with the popup)
- Reads only visible text
- DEMO auto Up/Down, no cookies / SSID / passwords
- Not financial advice. Brokers may ban automation.

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/)
2. Open: https://raw.githubusercontent.com/amardueno1-source/quotexbot-connect/main/quotexbot.user.js
3. Click Install
4. Open your demo-trade tab. The HUD sits on the chart. Toggle অটো ট্রেড.

Tampermonkey will auto-update this script from GitHub.
